Expo Frontend for Raspberry Pi Voice System

This folder contains a minimal Expo-managed React Native app scaffold.

Quick start (local development):

1. Install Expo CLI (if you don't have it):

   npm install -g expo-cli

2. From the `frontend/` folder install dependencies:

   npm install

3. Start Expo:

   npm start

Open with Expo Go on your phone or in an emulator.

Notes

- If you want, I can add API helpers and screens for viewing emails and flags.
